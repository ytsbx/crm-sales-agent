### B15-01 企微归一写接口绕开客户权限与数据范围

- **严重度：P1**
- **文件:行号：**
  - `backend/app/modules/wecom/router.py:260-286`（`bind-customer`，265 只要求 `wecom:manage`）
  - `backend/app/modules/wecom/router.py:289-313`（`create-customer`，294 只要求 `wecom:manage`）
  - `backend/app/modules/wecom/service.py:588-620`（`bind_customer` 用 `get_customer_or_404`）
  - `backend/app/modules/wecom/service.py:623-660`（`create_customer_from_contact` 直接调 `customer_service.create_customer`）
  - 对照：`backend/app/modules/wecom/router.py:709-716` 的 `import-customers` 显式要求 `customer:create` + `customer:assign`
- **触发条件：** 一个只有 `wecom:manage`（以及被 `require_wecom_action` 隐含的 `wecom:view`）、没有 `customer:view/assign/create` 的账号，调用 `POST /integrations/wecom/unbound-contacts/{id}/bind-customer`，`customer_id` 传任意客户 id；或调用 `create-customer` 建一个新客户。
- **后果：**
  - `bind_customer` 用 `customer_service.get_customer_or_404`，不是 `get_visible_customer`/`assert_customer_visible`，可以把企微联系人挂到别人的私有客户下，还能写 `is_primary`，绕开客户数据范围；
  - `create_customer_from_contact` 直接调 `customer_service.create_customer`，该服务本身不校验 `customer:create`（客户创建权限在客户路由），因此 `wecom:manage` 用户可以在没有客户创建权限的情况下建客户；
  - 两个接口都会写 `integration` 审计，但审计记录的是“企微归一”，不是客户归属变更，事后按客户审计查不到这次挂接。
- **证据代码：**

```python
# wecom/router.py
@router.post(".../bind-customer")
async def bind_customer(...,
    user: CurrentUser = Depends(require_wecom_action("wecom:manage")),
    ...
):
    result = await svc.bind_customer(... customer_id=payload.customer_id ...)

@router.post(".../create-customer")
async def create_customer(...,
    user: CurrentUser = Depends(require_wecom_action("wecom:manage")),
    ...
):
    result = await svc.create_customer_from_contact(...)
```

```python
# wecom/service.py bind_customer
customer = await customer_service.get_customer_or_404(session, customer_id)
contact = await create_contact_for_customer(...)

# wecom/service.py create_customer_from_contact
customer = await customer_service.create_customer(session, user, data)
```

- **建议：**
  - `bind-customer` 在路由层补 `customer:view`（若要改归属/主联系人，再加 `customer:assign` 或 `customer:update`），service 内改用 `get_visible_customer`，并在客户行锁内复核范围；
  - `create-customer` 补 `customer:create`；如果业务希望企微归一由管理员代建，应把 `customer:create` 写进权限矩阵，而不是靠 `wecom:manage` 隐式包含；
  - 审计至少记录 `before_customer_id/owner_id` 与 `after`，让客户归属链可查。
- **测试覆盖：** 未覆盖。`test_wecom_operation_permissions.py` 只测 transfer 相关权限；`test_wecom_customer_import.py:144` 直接调 service，绕过了路由权限。修复前应在隔离库补“只有 wecom:manage、无 customer 权限”的 403 用例。
