# 客户多人跟进现状访谈提纲（2026-11-26）

> 目的：搞清楚业务员现在实际怎么配合，决定系统要不要做"协作人"，以及规则怎么定。
> 不是考核，不要用"谁该负责"的语气问；先问现状，再问期望。

## 一、先找谁问

1. 先单独问 2–3 个当事人：刘帅帅、王松、周渲诺（小可爱、浙江梓晨、恒辉物流这几家都涉及他们）。
2. 再和销售主管一起对一遍，确认哪些是普遍做法、哪些是个别情况。
3. 单独问比开会问更容易听到真实情况，开会时容易互相客气。

## 二、开场白（照念即可）

> "我在梳理客户归属的规则，想听一下你们现在实际是怎么配合的。不是考核谁，是看系统怎么改才不给你们添乱。你按真实情况说就行。"

## 三、核心问题（按客户举例问，别问抽象概念）

### 1. 现在谁在跟
"小可爱这家，你和王松（或其他同事）都加着，现在实际是谁在跟？多久联系一次？"
（浙江梓晨供应链可以问王硕、多米、萌子这三个人分别谁在对接；恒辉物流问那 11 个人里实际谁在管。）

### 2. 报价谁出
"这家最近一次报价是谁报的？如果两个人都报过，客户拿到过两个价吗？后来怎么处理的？"

### 3. 成交算谁的
"如果这家成交了，业绩和提成现在怎么算？按订单还是按客户？有没有为这个争过？"

### 4. 资料能不能共享
"你希望同事能看到你客户的跟进记录、报价、订单吗？有没有哪些不想让同事看到的？"
（追问：成本、毛利、客户联系方式、私人备注。）

### 5. 提醒和没人管
"客户很久没联系，系统提醒现在发给你吗？如果两个人都在跟，你觉得该提醒谁？有没有出现过客户谁都没管、最后丢了的情况？"

### 6. 离职和交接
"如果有人离职或转岗，客户和手上的单子现在怎么交接？出过问题吗？"

### 7. 确认方案能不能接受
"如果系统让你们选一个主负责人，其他人做协作人——协作人也能看客户、记跟进，但客户资料和提醒算主负责人的，成交业绩还是按订单算——你们能接受吗？你觉得这种客户，主负责人应该按什么定？谁先加、谁一直在跟、谁成交，还是主管指定？"

## 五、问完要能回答的三个问题

1. 主负责人按什么规则定？（第一个加的人 / 一直在跟的人 / 成交的人 / 主管指定）
2. 协作人能看什么、能做什么？（只看跟进 / 也能报价下单 / 也能收款）
3. 提醒和回收算谁？（只算主负责人 / 所有协作人都提醒）

> 这三条定了，才能决定做"单负责人 + 协作人"，以及企微导入时多跟进人怎么自动落成主负责人和协作人。
